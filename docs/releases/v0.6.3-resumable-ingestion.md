# v0.6.3 Resumable Ingestion Jobs Release Notes

`v0.6.3 Resumable Ingestion Jobs` makes large repository ingestion recoverable
from browser reloads, frontend connection drops, and interrupted API processes.

## Included

- Background ingestion jobs with stable job IDs and lifecycle status.
- Additive API endpoints for starting, polling, recovering, and cancelling
  repository ingestion jobs.
- PostgreSQL-backed durable job persistence, with in-process status tracking
  when telemetry persistence is disabled.
- Frontend ingestion flow that starts quickly, polls job status, and recovers an
  active job after reload.
- Compatible legacy `/repositories/ingest` behavior for older clients and CLI
  usage.
- Checked-in OpenAPI contract updated for the new job endpoints.

## Scope

This release keeps the Local Alpha architecture local-first and does not add a
new worker service or queue. Fine-grained progress percentages, multi-user job
ownership, and v0.7 adaptive research streaming remain out of scope.

## Release Checks

- Package metadata and OpenAPI report `0.6.3`.
- `make test-all` is the broad local quality gate and includes frontend lint.
- v0.7 adaptive Quick, Balanced, and Thorough routing remains planned work.
