# v0.6.2 Intermediate Hardening Release Notes

`v0.6.2 Intermediate Hardening` prepares Repo Deep Research for v0.7 adaptive
research by making release-to-release evidence comparisons and feedback
recording more trustworthy.

## Included

- Version provenance for new monitoring runs, answer snapshots, and evaluation
  runs, including application version, git commit, and provenance labels.
- Conservative legacy version backfill support that marks inferred rows as
  inferred and leaves ambiguous rows unknown.
- Monitoring and evaluation UI fields for answer and evaluation versions.
- Idempotent feedback writes keyed by answer request identity, with stable
  duplicate handling.
- Frontend feedback state updates that disable repeated submission after a
  recorded response and preserve failed-submission recovery.
- Navigation locking and status messaging while repository ingestion is running.
- FastAPI long-ingestion responsiveness by moving synchronous ingestion off the
  event loop and removing the frontend production proxy header timeout.

## Scope

This is a hardening release, not a new research mode. Existing `/rag`,
`/research`, CLI, monitoring, and evaluation behavior remain backward
compatible. v0.7 adaptive Quick, Balanced, and Thorough routing remains planned
work.

## Release Checks

- Package metadata and OpenAPI report `0.6.2`.
- `make test-all` is the broad local quality gate.
- `make evaluate-relationship-graph` should be rerun with Qdrant available
  before claiming the v0.6.1 graph acceptance gate as production-verified or
  starting v0.7 implementation.
