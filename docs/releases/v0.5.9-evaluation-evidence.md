# v0.5.9 Evaluation Evidence Release Notes

`v0.5.9 Evaluation Evidence` prepares the Local Alpha for capstone review. It
keeps the application local-first and BYOK for live model calls, but makes
offline evaluation evidence easy to inspect without an OpenAI key.

## Reviewer Path

```bash
cp .env.example .env
cp .env.local.example .env.local
make stack-up
```

Then open:

- `http://localhost:3000/evaluations`
- `http://localhost:8000/docs`
- [../evaluation.md](../evaluation.md)

The `/evaluations` dashboard is seeded from PostgreSQL schema initialization
with curated retrieval and offline ground-truth answer summaries. Container
startup does not call OpenAI. Reviewers need `OPENAI_API_KEY` only to generate
new live answers or rerun the LLM judge.

## Included

- DB-backed ground-truth evaluation review tabs in the frontend.
- Persisted retrieval-evaluation and answer-evaluation summary rows for the
  reviewer dashboard.
- Seeded 2026-08-14 retrieval metrics for the development and Datapeek held-out
  datasets.
- Seeded 2026-08-16 Datapeek direct-vs-agentic ground-truth answer summaries.
- Updated README, setup, usage, and evaluation docs that map capstone evidence
  to reviewer actions.

## Scope

This remains a local Docker Compose release. Hosted deployment, managed cloud
persistence, multi-tenant authentication, and automatic code changes are still
out of scope.
