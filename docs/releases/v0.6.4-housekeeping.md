# v0.6.4 Housekeeping and Gate Alignment Release Notes

`v0.6.4 Housekeeping and Gate Alignment` prepares Repo Deep Research for v0.7
adaptive research by making current-facing documentation and the broad local
quality gate match the released v0.6.3 ingestion-job baseline.

## Included

- README, setup, usage, architecture, and follow-up plans describe `v0.6.3` as
  released and `v0.6.4` as the current release.
- Usage and architecture docs include the resumable ingestion job API and
  active-job recovery endpoint.
- `make test-all` now includes frontend lint before frontend tests, typecheck,
  and production builds.
- v0.7 planning explicitly preserves resumable ingestion jobs while adding
  adaptive research progress streaming.

## Scope

This release does not add new product behavior. It is a patch release for
documentation consistency, release readiness, and local quality-gate alignment.

## Release Checks

- Package metadata and OpenAPI report `0.6.4`.
- `make test-all` is the broad local quality gate and includes frontend lint.
- The relationship-graph acceptance gate remains the next required check before
  starting v0.7 implementation.
